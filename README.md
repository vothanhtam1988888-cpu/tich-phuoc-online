# TÍCH PHƯỚC ONLINE – Prototype 0.1

- Sân chùa 3D, chánh điện, hồ cá Koi, cây cổ thụ và ghế gỗ.
- Chọn nhân vật nam/nữ, đầu trọc/tóc ngắn, áo xám/nâu/vàng, nhập pháp danh.
- Di chuyển bằng WASD, phím mũi tên hoặc nút cảm ứng.
- Có thao tác ngồi nghỉ và ngắm cá.

Mở `index.html` bằng trình duyệt có Internet. Three.js được tải từ CDN.

Đưa lên GitHub Pages: tải toàn bộ file trong thư mục lên repository, sau đó vào Settings → Pages → Deploy from a branch → main → /(root).

Lưu ý: đây là prototype một người chơi. Chưa có đăng nhập, chat riêng, lưu hồ sơ hay nhiều người online; các tính năng đó cần backend ở giai đoạn tiếp theo.
